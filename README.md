# モヤリハット 1.4.0 — ローカル改修版

保存失敗時の入力保持、破損データの保護、保存できない状態の表示、身体部位の選択・削除の分離、各ステップの進行表示、自動下書き保存と再開を追加した版です。

## アプリを開く

アプリは静的HTML・CSS・JavaScriptで動作し、npmやビルドは不要です。このフォルダを静的Webサーバーで配信してください。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

`http://localhost:8000/` を開きます。記録は同じブラウザ・同じオリジン（URLのプロトコル、ホスト、ポート）の端末内保存領域にあります。配信URLを変更する前には、旧アプリでバックアップを書き出してください。

## 途中保存と再開

- 選択や強さの変更後、約400msで入力を自動保存します。ステップ移動時とページを離れる時にも保存を試みます。
- 「途中で休む」を押すと下書きを残してホームへ戻ります。
- 再読み込みや次回起動後は、ホームの「途中の下書き」から「続きから再開」を選べます。画面位置と選択内容も戻ります。
- 下書きと正式な記録は別です。「保存」で正式記録になり、対象の下書きを整理します。「下書きを削除」や明示的な破棄で削除できます。
- 別タブの下書きは別々に保存します。保存済みデータが別タブで更新された場合は、古い内容の上書きを止め、下書きを残して再読み込みするよう案内します。

保存領域が使えない場合は画面に表示します。入力直後400ms以内の強制終了、ブラウザの保存領域削除、端末故障では下書きが残らない場合があります。端末を共有する場合、下書きも端末内に残ることに注意してください。外部への自動送信は追加していません。

## 読み込み・保存に失敗した時

記録保存に失敗したら入力と保存画面を保持します。保存領域を確保して再試行できます。破損が疑われる保存データは初期状態で自動上書きせず、設定画面から原文を書き出して退避できます。バックアップ復元・初期化は既存の確認操作を通して行います。

既存の `MOYARIHAT_STATE_V1` とデータ形式v1〜v3の読み込みは維持しています。Service Workerの登録やファイル名は変更していません。

## 回帰テスト

Node.js 22以上で実行します。追加依存パッケージは開発・テスト用です。

```sh
npm ci
npm test
```

実Chromeによる代表確認はChrome/Chromiumの実行ファイルを指定します。隔離したブラウザと合成データで実行し、ローカルサーバーを自動起動・終了します。

```sh
CHROME_PATH=/path/to/chrome npm run test:browser
```

Linuxの制限された環境向けに `--no-sandbox` を指定しています。代表テストではService Workerを無効にしています。実端末のSafariやPWA更新・オフライン動作はこの検証に含まれません。

この一式はローカル改修ソースです。GitHubへのPush・本番公開は行っていません。
